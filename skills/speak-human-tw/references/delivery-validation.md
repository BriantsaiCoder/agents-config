# 保真與交稿檢查

模式與授權依 [SKILL.md](../SKILL.md)；未獲選的 Check-first 項目保持原文。六類保護內容依 [protected-list.md](protected-list.md)。

### 5. 保真回讀

改完全文後逐項核對：

1. 保護清單六類是否原封不動（credential／secret 的敏感值除外，必須遮罩）
2. 原文的事實、數字、具體判斷與行動在改寫版都找得到；[改寫程序](rewrite-procedure.md)第 4 步已移除的空泛效益不因保真要求而補回。已知事實須留在交付的改寫正文，僅在刪除說明或補充詢問提到不算保留
3. 沒有新增原文沒有的事實（尤其不能為了「更具體」編造數字或來源）
4. 語域統一：公告仍像公告、貼文仍像貼文
5. 作者的立場與觀點沒被改變

## 交稿

依所選模式輸出；Rewrite 交最終版本，必要時附簡短修改重點。沒有問題就放行，不為了展示工作而改寫 SNF 文本。

- 原文缺少具體事實時，標「（需作者補充：⋯⋯）」；不編造數字、來源、故事、立場或情緒反應。
- 可疑引用保留原句並標「〔需查證來源〕」；本 skill 不代做事實查核。
- 功能性標題、表格、步驟、checklist 與 code block 保留。中文 prose 使用台灣用語與全形標點，技術識別字、引用及 evidence 不受標點替換影響。
- 只拿到節錄時，密度規則以節錄為範圍，必要時提醒全文自查。
- 長文回讀直接性、節奏、信任度、真實性與精煉度；先修有具體依據的問題，不用主觀分數證明完成。
