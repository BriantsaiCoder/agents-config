# 改寫程序

依 [SKILL.md](../SKILL.md) 選定模式後執行；本附件不擴大授權。

先以 [scenes.md](scenes.md) 判情境與力度，只有讀者／用途會實質改變範圍時才詢問。動筆前依 [protected-list.md](protected-list.md) 圈出六類保護內容；credential／secret 的值先遮罩。

### 3. 判改寫範圍（長文防縮水）

- **短文（約 1000 字以下）**：可刪空話、併句與重排，保留每個資訊點。
- **長文（約 1000 字以上）**：盡量逐句對應，保留故事結構、節奏句與轉場；整句刪除只限不承擔資訊或節奏的空話，並在修改摘要交代。Check-first 將刪句列入待選清單。
- 使用者明示「一句都別刪」時只做句內調整。

### 4. 逐類改寫

按 [references/patterns.md](patterns.md) 的 38 種痕跡逐類處理，優先序：

1. **先刪**：對話殘留、免責聲明、通用積極結論、解說導引句、公式化開場（時代大帽子），刪掉不用補
2. **再具體化**：誇大意義、廣宣語氣、模糊歸屬、立場真空（各有優缺點、因人而異），改成有依據的具體敘述。混合句先拆開：保留原文可辨識的事實、工具名稱及其用途，只刪沒有依據的評價／效益；缺乏依據的效益不得留在正文當作已證實結果；不能只換成較白話的效益宣稱。另標需作者補充，不因缺效益數據而刪掉已知事實。整句刪除只適用於沒有可保留資訊的空話。
3. **再降格式**：破折號、粗體、emoji、表格、編號列表、首先／其次／最後三段式，只處理裝飾性或無資訊功能者；能幫讀者定位、比較或執行的標題、清單、表格、checklist 與 code block 保留，技術情境優先
4. **同步跑台灣在地化**：中國用語替換與全形標點，見 [references/taiwan-localization.md](taiwan-localization.md)

模式優先、詞表兜底：遇到沒列出的新說法，先問它屬於哪一類既有模式，不要求逐詞命中。

**禁止換湯不換藥**：刪掉一句空話後不得補上同族的另一句空話（刪「標誌著」不能補「象徵著」；刪「賦能」不能補「加值」）。
