# 02 設定層制度：tier 分層 + agents-sync + fingerprint 探針

> 適用：全 host｜載入：無（PROPOSAL，未生效）
>
> 設計軸心：唯一把驗證做到「context 級」的方案——每個常駐檔帶唯一 fingerprint codeword，30 秒可證「此刻真的在 context 裡」。歷史兩起事故的共同點都是檔案層正常、context 層死透；本層讓該命題變成可機械重驗的常態。

## 目錄佈局（`~/.agents/` 終局形態）

```
~/.agents/                          # 單一正本層（Step 1 git init；私有 remote 備份）
├── README.md                       # 本層定位、讀者=AI 宣告、再生指令、tier 定義
├── CONVENTIONS.md                  # AI 讀者書寫規範實體檔（見 05；agents-sync lint 據此執行）
├── .gitignore                      # 排除 .DS_Store、*.bak；dist/ 刻意「進」版控供 drift diff
├── core/                           # ── 共用規則正本（檔 = 同步強度單位）──
│   ├── tier0-safety.md             # 安全紅線 ≤30 行；檔首寫死衝突裁決鏈；三家 100% 常駐
│   ├── tier1-workflow.md           # 工作流規則（提問門檻、plan 分級、deps-check、commit 可重現性…）
│   ├── tier2-style.md              # 風格（zh-TW commit、comment policy、用詞對照表）
│   └── routing.md                  # 【兩案合併】dev-workflow 路由區塊唯一原稿 + host 無關 skill routing 判準（≤30 行 cap）
├── rules/                          # stack pin 正本（自 ~/.claude/rules 遷入 8 檔；pin 區塊以 <!-- PIN --> 包裹供抽取）
├── skills/                         # 既有 50 個 + 新增 dev-workflow/、sdd/（見 03）
│   └── ecpay/UPSTREAM.txt          # 內嵌 .git 移除後記 upstream URL + 最後 SHA（vendor 化）
├── hooks/                          # 共用 hook script 正本（patch-*-mcp.sh 先遷；阻擋型三支待 Codex PreToolUse 實測後）
├── hosts/
│   ├── codex-delta.md              # Codex 專屬（Closeout Ledger 原文收割處、spawn_agent 名單、built-in reviewer 路由）
│   └── copilot-delta.md            # Copilot 真 host 事實（取代現行檔：刪假繼承宣稱與 9 死名）
├── bin/
│   └── agents-sync                 # 生成器（~60 行 sh）+ 檔頂 targets 資料表；--check / --bootstrap / --doctor（巡檢：斷鏈 0、manifest 相符、override 不存在、三家探針指令輸出。併入單一腳本＝少一個 drift 面，見 06 C-R4）
├── dist/                           # 生成產物（進版控）：manifest.tsv、codex-AGENTS.md、copilot-shared.instructions.md、copilot-instructions.md、skill-index.md
├── attic/                          # 退役歸檔（git 可考古）：.skill-lock.json、AGENTS.override.md、舊 32KB AGENTS.md…
└── proposals/                      # 本提案目錄
```

各 host 消費面（不在 `~/.agents` 內但被本設計改寫）：
- `~/.claude/CLAUDE.md`：頂部 4 行 `@import ~/.agents/core/*`（原生機制，零生成、不可能 drift）+ Claude 專屬層。
- `~/.claude/rules/*.md`：改**相對** symlink `../../.agents/rules/*.md`；`UNVERIFIED:` rules loader 是否追 symlink——遷移步驟內建探針，失敗則 fallback 為 agents-sync 生成目標。
- `~/.claude/skills/*`：50+2 條 symlink 改相對路徑（修換機即斷）。
- `~/.codex/AGENTS.md`：= `dist/codex-AGENTS.md` 部署副本（**override 已刪**，回歸 boring default 載入）。
- `~/.copilot/instructions/00-agents-shared.instructions.md` + `copilot-instructions.md`：= dist 部署副本（已驗證整檔注入路徑；棄用 `COPILOT_CUSTOM_INSTRUCTIONS_DIRS`——附加 vs 取代語意未活體驗證且依賴 shell rc）。

## 衝突裁決鏈（寫死 tier0-safety.md 檔首）

```
user 當下明示 > repo 層協作檔 > tier0 hard rules > host delta > 被 invoke skill 的程序步驟 > 通用慣例
約束：repo 層對 tier0 只可「加嚴」不可「放鬆」；放鬆 tier0 只有 user 當下明示一途。
衝突條文引用一律用規則 ID（如 [T0-3]），讓裁決過程可稽核。
```

拒絕「host delta > hard rules」的倒置——1.5KB delta 檔悄悄凌駕 32KB 主檔正是本次要根治的事故類別。

## 同步機制（每家用「已驗證的原生機制」，原生不夠才生成）

| Host | 機制 | drift 面 |
|------|------|----------|
| Claude | `@import`（core）+ 相對 symlink（rules/skills）——零生成 | 源改即生效，不可能 drift |
| Codex | agents-sync 組裝 `dist/codex-AGENTS.md`（banner + tier0/1/2 + PIN 表 + skill-index + **routing 區塊** + codex-delta）部署 | 生成檔可被手改 → no-clobber 守護 |
| Copilot | agents-sync 組裝兩檔部署至 instructions/ 與 copilot-instructions.md | 同上 |

**部署映射資料化**：source→output→host 對應抽成 agents-sync 檔頂資料表（targets.tsv 形式）；新增第 4 家 CLI 只加一列資料、不改腳本邏輯。前置：新 CLI 的載入機制**必須先過活體探針**才准上線。

**manifest 路徑一律 `$HOME` 相對**，agents-sync 展開；`--bootstrap` 子命令一鍵重建全部相對 symlink + 部署三家。新機 restore = clone 兩 repo（agents + dotclaude）+ 跑一次 bootstrap。settings.json / hooks.json 內 hook 路徑用 `$HOME` 變數不寫死使用者名。

## 防 drift 三重守護（強度隨 tier 遞減）

**tier0（100% live）**：
1. **SessionStart 自動再生**：Claude settings.json 與 Codex hooks.json 各掛 `agents-sync --check`——hash 不符即冪等再生，無「記得跑」環節。Copilot 無 user-level hook，其部署目標由另兩家任一 session 順帶修復（守護不必在該 host 內執行，只需高頻執行）。**再生前最小自檢**：skill-index 行數 == skills 目錄數、fingerprint 句存在、輸出非空——不符則 fail-loud 不部署（防生成器 bug 把壞輸出放大成三家同時中毒）。
2. **no-clobber**：部署目標 hash ≠ manifest 記錄（有人手改生成檔）→ **拒絕覆寫**、輸出 diff、逼回正本修改——唯一無資料損失的處置。生成檔首行 banner：`<!-- GENERATED by ~/.agents/bin/agents-sync @<git-sha> hash:<sha256 前 8 碼> — 勿手改；改 ~/.agents/core|hosts|rules -->`（git sha + 內容 hash 讓「這份快照多舊」機械可查）。
3. **機械下沉**：git pre-commit gitleaks（host 無關、三家 + 人工 commit 全覆蓋）；hook 內 `command -v gitleaks || exit 1` **fail-closed**——缺工具擋 commit 而非靜默通過。修剪 Codex default.rules 兩條無條件放行（approval 層煞車復位）。

**tier1**：同管線搭載；容忍最多一個 session 延遲。
**tier2**：明標「host 間差異可接受」，只靠 git diff 巡檢；發現實害才升 tier（守護強度與成本成比例，不假裝全防）。

**doctor 判定語彙**：`DRIFT`（有人手改部署檔）與 `STALE`（改了 source 忘 sync）必須區分輸出——處置不同（前者逼回正本，後者直接再生）。

## agents-sync 內建 lint（build fail 條件）

1. core/hosts 檔中反引號引用的 skill/command 名必須存在於 `skills/`，或明標 `host:<name>-only` 豁免（9 死名事故的結構性根絕；手寫 skill 清單一律禁止，索引只准機械生成）。
2. `rules/*.md` 必有 paths frontmatter（防 cookbook 式常駐稅回歸）。
3. `~/.claude/rules/` 下禁非 symlink 散檔（防 host 端偷長分岔正本）。
4. 語意易漂移的 MUST 必附 ✅/❌ 最小對照例（**反例義務**；R5 教訓：沒有「❌ 不可改成 `Math.Min(x,1)`」這句，正確實作會被合理化改壞）——無反例的模糊 MUST 視為未完成條目。
5. 硬預算：tier0 ≤ 30 行、routing 區塊 ≤ 30 行、三家常駐生成總量 ≤ 10KB——超標 build fail（規則越多每條權重越低；這是對模型注意力的工程約束）。
6. superpowers 版本一致性：三家 plugin 註冊版本 grep 比對，不一致警告（防三家跑不同版 workflow 執行件）。

## Fingerprint 探針（context 級驗證的核心）

每個常駐檔含一句唯一 codeword（如 `FP:AGENTS-T0-2026Q3`）。`agents-sync --doctor` 輸出三家探針指令：

```
claude -p '輸出 context 中所有 FP: 開頭 codeword'
codex debug prompt-input 'x' | grep -c 'FP:AGENTS-T0'      # 依 0.142.5 介面；升版後指令可能變動
copilot -p '複誦 context 內 FP: 開頭 codeword' --available-tools=
```

**任何 CLI 升版後，跑三探針列為必跑項（寫進 tier0，不靠記憶）。** 未驗證的載入宣稱一律 `UNVERIFIED:` 前綴，禁止肯定句——C 檔一句假宣稱的成本已知：完整 Hard Rules 失守一個月（殘存僅英文摘要，見 01 F1）。

## Failure scenarios 對策表（8 條，已織入上文的守護即為對策）

| # | 情境 | 對策（本設計內建） |
|---|------|--------------------|
| 1 | 換新機 restore（$HOME 不同） | manifest $HOME 相對路徑 + `--bootstrap` 一鍵重建 |
| 2 | CLI 升版改載入行為 | 部署真檔不靠 symlink 假設；升版後三探針必跑（tier0 條文）；探針指令旁註明所依版本 |
| 3 | 用戶手改生成物 | no-clobber 拒覆寫 + banner 指回正本——唯一無資料損失路徑 |
| 4 | 新增第 4 家 CLI | targets 資料表加一列；載入機制先過活體探針才上線 |
| 5 | 規則衝突裁決分岔 | tier0 檔首裁決鏈 + 規則 ID 引用 |
| 6 | secrets 混入共用層 | pre-commit gitleaks fail-closed；推 remote 前全掃；stitch key rotate 帶外獨立待辦 |
| 7 | 長期只開 Copilot（守護不對稱歸零） | 明標已知降級（tier 語意）；可選 launchd 每日 `agents-sync --check` |
| 8 | 再生腳本本身出 bug | 再生前最小自檢 fail-loud；dist/ 進版控可 git diff 察覺 |

## Tradeoffs（明示接受的代價）

1. Codex/Copilot 走生成而非引用：兩家無 import 下唯一不靠假設的做法；代價由 banner + no-clobber + dist 版控緩解。
2. 三家實體組裝形態不同：除錯看各自組裝結果——三探針即為此固化。換得 Claude 端零生成、零 drift 面。
3. 刪 override 回歸 boring default：消除整檔取代 footgun；殘餘風險（未來工具重建 override 靜默遮蔽）→ `agents-sync --doctor` 把「override 不存在」列常態巡檢。
4. ecpay vendor 化：失去 git pull 便利，換單一 repo 乾淨版控（submodule 三家 loader 行為未驗證，否決）。
5. tier2 容忍 drift：三家人格微差存在；某條造成實害 → 移入 tier1/0 即自動升級守護。
6. Codex/Copilot 常駐注入 ~8–10KB：無條件掛載機制的固有成本；以硬預算控制，stack 細節留在只有 Claude 能條件掛載的 rules/，兩家只吃 PIN 摘要——接受兩家在 stack 細節上比 Claude 淺。
7. 單點故障集中 `~/.agents`：git + 私有 remote 後，仍嚴格優於現狀（三處無版控各自漂移，其一已假載入一個月）。
8. 阻擋型 hook 暫不遷 Codex：PreToolUse 無觸發證據——假守護比沒守護糟；實測通過才遷，期間明標降級。
